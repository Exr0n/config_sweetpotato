Helium centered overlay and exact modifier-held MRU

Chosen: pinned albus-flashquotes/arc MV3 source in helium/extensions/arc.
Palette overlays the current normal webpage, not a new-tab replacement. Cmd-Shift-K opens it. Ctrl-Q previews recent tabs, repeated Q cycles while Control stays held, releasing physical Control commits selection. MRU is session-stored and survives service-worker suspension, not guaranteed across full browser exit.

One-time activation, during your next normal browser session:
1. Open chrome://extensions in Helium yourself, enable Developer mode, choose Load unpacked and select /Users/exr0n/.config/helium/extensions/arc.
2. Open chrome://extensions/shortcuts and verify Arc toggle-palette is Command-Shift-K, quick-switch is Control-Q. Resolve conflicts first.
3. Only after both work, import helium/arc-shortcuts.karabiner.json into Karabiner as an opt-in complex modification. This asset is NOT added to the dirty running karabiner.json. Enable its two Helium-scoped rules. Cmd-T becomes Cmd-Shift-K; Control-Tab becomes Control-Q with optional Shift preserved. Native input remapping remains to be verified after activation.
4. Test Cmd-T over an ordinary page, type a tab title, Enter. Test holding Control and tapping Tab repeatedly, releasing Control to commit; Shift-Tab reverses, Escape cancels.

Browser-internal pages, blank new tabs, Web Store and noninjectable pages cannot host webpage overlays; upstream uses toolbar popup or extension-page fallback there. This is a Chromium limitation, not a claim of universal centered overlay.
