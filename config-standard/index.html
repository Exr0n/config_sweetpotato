macos.keyboard.caps-control-escape

Caps Lock ⇄ Control

macOS owns the modifier swap. Karabiner adds only one overlay: tapping the remapped Control key alone emits Escape.

Install

Review the public repository, then run:

git clone https://github.com/Exr0n/config-standard.git
cd config-standard
./install.sh macos.keyboard.caps-control-escape

For coding agents

Follow the repository’s agent instructions. The installer merges safely into the selected Karabiner profile and preserves unrelated mappings.
